# DicoSmart – download

**DicoSmart** compila, controlla ed emette le **dichiarazioni di conformità degli impianti** (D.M. 37/2008): modello
Allegato I, regole normative, allegati, schema dell'impianto, manuale d'uso e manutenzione, archivio cifrato sul tuo computer.

## Scarica

➡️ **[Ultima versione](https://github.com/jjonathancalleri-alt/dicosmart-download/releases/latest)**

- **Mac** (Apple Silicon e Intel): file `.dmg`
- **Windows** 10 e 11: file `.msi`

**Prova gratuita di 30 giorni**, senza registrazione. Dopo la prova serve una licenza (singola o per più PC).
Le versioni installate si aggiornano da sole.

## Come installare

**Mac** – apri il `.dmg` e trascina DicoSmart in Applicazioni. La prima volta: clic destro sull'app → **Apri** → Apri.
Se il Mac la blocca: Impostazioni di Sistema → Privacy e sicurezza → **Apri comunque**.

**Windows** – apri il `.msi`. Se compare "Windows ha protetto il PC": **Ulteriori informazioni → Esegui comunque**.

## I tuoi dati

I dati restano sul tuo computer (o sul disco di rete che scegli), in un archivio cifrato protetto dalla tua password.
Nessun server, nessun abbonamento a servizi esterni.
